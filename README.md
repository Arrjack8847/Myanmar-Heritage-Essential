# Myanmar Heritage · Essential

JN-W01 — a mobile-first Myanmar-inspired wedding invitation template by JackNex Studio.

Modern Heritage design: ivory paper, maroon, antique gold, layered ceremonial decoration and connected GSAP scroll motion.

## Run locally

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Customization

Edit `data/invitation.ts` to change the sample names, ceremony date and schedule, venue, map URL, gallery images, messaging, and contact address.

**Demo content:** all couple and event details are fictional; the gallery uses sample external photography for preview only. Replace photos with licensed/client-approved assets before delivering to a couple.

## Package scope

Five core sections, mobile-first animations, gallery viewer, and two configurable demo Standard Add-ons (countdown and add-to-calendar). RSVP collection and other Premium Add-ons are intentionally not included.

Built with Next.js, React, TypeScript, CSS, GSAP and ScrollTrigger.
